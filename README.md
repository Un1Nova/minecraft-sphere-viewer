# Сфера / 196

Интерактивный проект на React, TypeScript и Three.js. В 3D камеру можно вращать, приближать и перемещать внутрь. Круглый вырез в ближней стенке плавно следует за камерой; дальняя стенка остаётся непрозрачной. В режиме 2D доступен точный послойный блочный чертёж с размерами ступенек.

Сайт: https://un1nova.github.io/minecraft-sphere-viewer/

## Конструкция

| Элемент | Размер |
| --- | --- |
| Внешний габарит сферы | 196 × 196 × 196 блоков |
| Оболочка | Один слой граничных кубических блоков |
| Площадь каждой стеклянной платформы | 112 × 112 блоков, ровно 7 × 7 чанков |
| Рабочие этажи | 5; чистая высота каждого — 16 блоков |
| Технические разделители | 4; общий габарит каждого — 5 блоков |
| Стеклянные перекрытия | 10; толщина каждого — 1 блок |
| Общая высота конструкции с внешним полом и крышей | 102 блока |

В технические 5 блоков входят нижняя и верхняя стеклянные плиты по одному блоку и 3 блока открытого воздуха. Все платформы парят: колонн, стен, подвесов и вертикальных связей нет. Светящиеся кубики находятся исключительно в полостях внутри сферы, за пределами центральной рабочей области.

Сфера строится на общей целой кубической сетке. Воксель входит в исходный шар, если его центр находится на расстоянии не больше 98 от начала координат. Из этого шара остаётся только один граничный слой: блоки, имеющие хотя бы одного внешнего соседа по шести направлениям. Это цифровая ступенчатая оболочка, а не гладкая математическая поверхность.

Сетка чанков привязана к краям платформ X/Z = −56 и 56. В локальных координатах границы чанков проходят через 8 + 16k, поэтому платформа занимает семь полных чанков без дробных краёв. Сфера диаметром 196 пересекает область 13 × 13 чанков с внешними границами −104 и 104 (208 блоков); четыре угловых чанка этой области могут не содержать блоков сферы. Для переноса в Minecraft разместите локальный центр сферы на координатах X/Z, равных 8 по модулю 16, и добавьте выбранную высоту центра.

## Управление

- Мышь или один палец — вращение камеры.
- Колесо или жест двумя пальцами — приближение.
- Правая кнопка мыши или перемещение двумя пальцами — сдвиг камеры.
- Предустановки позволяют посмотреть спереди, сверху и изнутри.
- Настройки открываются кнопкой справа сверху; второстепенные параметры свёрнуты.
- Плотность оболочки регулируется отдельно от размера круглого выреза. Значение 100% сохраняет сплошные чёрные блоки вне отверстия.
- Чанки: выключено; тонкие красные вертикальные границы через 16 блоков; жёлтые границы с зелёной сеткой на вертикальных плоскостях с шагом 4 блока.
- В 2D доступны виды спереди, сбоку и сверху, все 196 слоёв, приближение и перемещение чертежа.
- Кнопка линейки включает размеры. Для читаемости на общем виде подписаны более длинные ступеньки одной симметричной четверти; при приближении появляются единичные. Нажмите любую ступеньку, чтобы увидеть её точную длину, или перебирайте контур стрелками в карточке.
- Срезы показывают настоящие блоки выбранного слоя. Центральный горизонтальный срез проходит воздух рабочего этажа; верхняя стеклянная плита видна на слое 149 (Y = 50.5).

## Локальный запуск

Требуется Node.js 22.12 или новее; для CI используется Node.js 24.

```bash
npm ci
npm run dev
```

## Проверка и сборка

```bash
npm test
npm run build
npm run preview
```

Сборка находится в `dist/`. Приложение не требует серверной части, API-ключей, внешних текстур или учётной записи посетителя. Все текстуры и геометрия формируются локально в браузере.

## GitHub Pages

В репозитории открыть **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow `.github/workflows/deploy.yml` проверяет геометрию, собирает приложение и публикует его после изменений в `main`. Для pull request выполняются проверки без публикации. Адрес сайта возвращается шагом deployment и отображается в окружении `github-pages`.

Используется относительный `base: './'`: ресурсы и Web Worker загружаются корректно и из корня, и из подпапки репозитория.

## Как устроено

- `src/scene/geometry.ts` — воксельная оболочка и детерминированное размещение звёзд.
- `src/scene/shell.worker.ts` — построение оболочки вне основного потока.
- `src/scene/SphereScene.ts` — рендер, стекло, управление камерой и её срез.
- `src/scene/cutaway.ts` — перспективная геометрия круглого отверстия.
- `src/blueprint.ts` и `src/BlueprintView.tsx` — точные слои оболочки, ступеньки и интерактивный SVG-чертёж.
- `src/chunks.ts` и `src/scene/chunks.ts` — общая привязка чанков и тонкая трёхмерная сетка.
- `src/model.ts` — размеры, высотные отметки и настройки.
- `src/App.tsx` — интерфейс.

Блоки сгруппированы по маскам открытых граней и отрисовываются экземплярами. Соседние внутренние грани не передаются на GPU. Поэтому оболочка из почти ста тысяч блоков не создаёт почти сто тысяч отдельных объектов сцены. Срез изменяет видимость в шейдере без пересоздания геометрии; исчезнувшие фрагменты не перекрывают содержимое буфером глубины.

3D зависит от возможностей WebGL устройства. Снижение качества ограничивает плотность рендеринга, не меняя размер и форму конструкции. Режим 2D использует SVG и работает без WebGL.
